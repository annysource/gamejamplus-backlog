# GameJamPlus Backlog

Transforme avisos da GameJamPlus em uma lista curta de tarefas, com prioridade, responsável, prazo e origem da informação.***

Serve para organizadores de sedes e equipes participantes.

------ disclaimer: NAO SUBSTITUI VERIFICAÇÃO HUMANA PRA DOUBLE CHECK DAS INFORMAÇÕES!

## 1. Instale

1. Baixe este repositório: clique em **Code → Download ZIP** no GitHub.
2. Extraia o ZIP.
3. Copie a pasta **gamejamplus-backlog**, que contém o arquivo **SKILL.md**, para a pasta de skills do Codex:
   - **Windows:** `%USERPROFILE%\.codex\skills\`
   - **macOS/Linux:** `~/.codex/skills/`
4. Abra uma nova conversa no Codex. Se a skill não aparecer, reinicie o aplicativo.

No Windows, o resultado deve ser:

```text
C:\Users\SEU_USUARIO\.codex\skills\gamejamplus-backlog\SKILL.md
```

**Atenção:** não deixe uma pasta duplicada no caminho, como `gamejamplus-backlog/gamejamplus-backlog/SKILL.md`.

## 2. Use

Copie e cole no Codex, trocando o nome do grupo e seu papel:

```text
Use $gamejamplus-backlog para ler o grupo “NOME DO GRUPO”
no WhatsApp Web e gerar meu backlog dos últimos três dias.
Sou organizador da sede “NOME DA SEDE”.
Quero o resultado compacto, com IDs e origem de cada tarefa.
```

Se você participa como jammer, troque a frase sobre a sede por:

```text
Sou participante da equipe “NOME DA EQUIPE”.
Inclua apenas tarefas que se aplicam à minha equipe.
```

## 3. Dê acesso às informações

Para ler diretamente o WhatsApp Web, o Codex precisa ter uma ferramenta de navegador compatível e o WhatsApp deve estar conectado. A skill sozinha não instala essa ferramenta nem conecta sua conta.

**Sem acesso ao navegador?** Cole as mensagens na conversa ou anexe um arquivo exportado e peça:

```text
Use $gamejamplus-backlog para transformar estas mensagens
em um backlog compacto. Sou organizador de sede.
```

## O que você recebe

| ID | Prioridade | Tarefa / responsável | Prazo | Critério de conclusão | Origem |
|---|---|---|---|---|---|
| GJP-01 | Alta | Conferir envio / organizador — validar | Não informado | Envio confirmado na plataforma | Autor, data e horário |

Os IDs permanecem nas atualizações. Uma tarefa começa como **A verificar** quando não há prova de que está pendente ou concluída.

Para atualizar, continue na mesma conversa ou forneça o backlog anterior:

```text
Atualize o backlog com as novas mensagens.
Mantenha os IDs e destaque mudanças, prazos e bloqueios.
```

## Quer receber automaticamente?

Peça ao Codex para configurar a recorrência e informe dias, horário e fuso. Para receber por e-mail, informe também o destinatário e autorize o envio.

**Instalar esta skill não cria automação nem envia e-mails.** Esses recursos dependem das ferramentas e conexões disponíveis no seu ambiente.

## Privacidade e vínculo

A skill não inclui credenciais, destinatários ou acessos do criador. Compartilhe apenas informações que você pode compartilhar e revise dados pessoais antes de publicar resultados.

Projeto independente para a comunidade. Não é uma ferramenta oficial da GameJamPlus.
